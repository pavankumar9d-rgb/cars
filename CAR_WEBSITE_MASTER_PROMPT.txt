7. 360° ORBIT
====================================================

Every car must support a full 360-degree rotation.

The rotation must be:

continuous
cinematic
damped
predictable

No snapping.

Use interpolation/lerp or damping.

9. LENIS + GSAP
====================================================

Initialize Lenis.

Do not create competing animation clocks.

Do not create multiple independent RAF loops.

====================================================
13. EXPLODED VIEW — CRITICAL
====================================================

The exploded view must be a TRUE 3D transformation.

Do NOT fake it by:
- scaling opacity
- swapping to the MP4
- swapping to JPG frames
- teleporting the entire car
- moving every object by the same vector

The MP4 and extracted frames are references.

The actual GLB should be exploded by moving its real components.

Concept:

BODY
up/out

HOOD
forward/up

ENGINE
down/slightly forward

TRANSMISSION
down/back

CHASSIS
down

FRONT WHEELS
outward

REAR WHEELS
outward

SUSPENSION
outward

BRAKES
outward with wheels/axles

BODY PANELS
slightly outward

The exact directions and distances MUST be derived from the reference videos
and the actual model coordinate system.

Create:

const explodedTargets = {
  body: ...,
  hood: ...,
  engine: ...,
  transmission: ...,
  chassis: ...,
  frontLeftWheel: ...,
  frontRightWheel: ...,
  rearLeftWheel: ...,
  rearRightWheel: ...,
  suspension: ...,
  brakes: ...
};

Store immutable assembled transforms.

Never do:

object.position.x += value

because that causes cumulative drift.

Instead:

current = lerp(assembled, exploded, explosionProgress)

or equivalent stable interpolation.

Scrolling backwards must return every component to the exact assembled pose.

Then reverse exactly when scrolling backward.

Use smooth easing, but keep scroll responsiveness.
